# 阶段 12：带来源的只读笔记聊天

笔记页新增章节选择和聊天框，会话及消息持久保存，消息绑定笔记版本。发送动作进入同一 Worker 队列，支持既有取消/手动重试。上下文仅包含所选章节、对应字幕和该笔记版本最近六条历史消息；超出预算/上下文时明确失败，不静默截断所选章节。回复最多一次修复，引用片段和原文均校验；聊天不会发布笔记或重出题。

修改 study 路由、study_repository、operations、测试模型和 TaskView；新增 note_chat 服务、NoteChat 组件及集成测试。沿用 D2 原文核对、D1 JSON 提取和 SafeMarkdown 安全显示，没有新增上游源码、RAG 或多 Agent。

实际验证：44 项相关后端测试、13 项前端测试、类型检查与 Ruff 通过。覆盖消息幂等、持久读取、跨课程隔离、无效章节拒绝、有效引用、正式资料不变及版本基础回归。真实回答质量、提示注入下的模型语义表现仍待云端验收；本地权限和引用校验不依赖模型守规。下一阶段为偏好与草稿版本。
